技术支持

如何开启

  1. 打开「设置 → Safari 浏览器 → 扩展」。
  2. 开启「素页 规则拦截」。
  3. 开启「素页 AI 过滤」，并把「所有网站」设为「允许」。
  4. 打开素页 App，点「立即同步规则至 Safari」。

常见问题

广告没去掉？ 确认两个扩展都已开启，然后回到 App 点「立即同步规则至 Safari」，再刷新网页。

页面内容被误删？ 可提交不含敏感信息的问题说明，供我们排查；不保证在特定版本修复。临时可在 Safari 地址栏「大小」菜单里对该网站关闭扩展。

会不会上传我的浏览记录？ 不会。所有判断都在手机本地完成，详见 隐私政策。

反馈

请在 GitHub Issues 提交问题，说明问题及 iOS 版本；如需网址或截图，只提供可公开的页面，并先移除个人信息。GitHub Issues 是公开的，请勿提交登录态页面、浏览记录、账号、订单、密码或其他敏感信息。

Support

Turn it on

  1. Open Settings → Safari → Extensions.
  2. Turn on "Plainpage Rule Blocking".
  3. Turn on "Plainpage AI Filter" and set "All Websites" to "Allow".
  4. Open the Plainpage app and tap "Sync rules to Safari".

FAQ

Ads still showing? Make sure both extensions are on, tap "Sync rules to Safari" in the app, then reload the page.

Something on a page disappeared by mistake? You can report the issue without sensitive information so we can investigate; a fix in a specific release is not guaranteed. Meanwhile you can turn off extensions for that site from the page menu in Safari's address bar.

Is my browsing uploaded? No. Everything runs on your iPhone; see the Privacy Policy.
